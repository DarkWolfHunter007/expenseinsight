## Quick Start Options

### Option 1: Run with Docker Compose (Recommended)

1. Start both the Backend (FastAPI) and Frontend (Flutter Web / Nginx) containers:
   docker compose up --build -d

2. Access the Application:
   • Frontend Web Dashboard: http://localhost:3000 (or http://localhost)
   • Backend REST API: http://localhost:8000
   • Interactive Swagger Documentation: http://localhost:8000/docs
   • Health Check Endpoint: http://localhost:8000/health

3. View Container Logs:
   docker compose logs -f backend
   docker compose logs -f frontend

4. Stop Containers:
   docker compose down

---

### Option 2: Share Live via Cloudflare Tunnel & QR Code

1. Ensure the Docker containers are running (Option 1).
2. Run the sharing script:
   python share_live.py

3. What Happens:
   • Creates a secure public HTTPS tunnel to http://localhost:3000
   • Generates a public URL (e.g. https://xyz.trycloudflare.com)
   • Prints an ASCII QR code in your terminal for instant mobile scanning

---

### Option 3: Run Locally (Python + Flutter)

1. Start the FastAPI Backend:
   Windows PowerShell:
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     pip install -r backend/requirements.txt
     uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000

   macOS / Linux Bash:
     python3 -m venv .venv
     source .venv/bin/activate
     pip install -r backend/requirements.txt
     uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000

2. Run the Flutter Frontend:
     cd mobile/flutter_app
     flutter run -d chrome        # Web / PWA
     flutter run -d windows       # Windows Desktop
     flutter run -d macos         # macOS Desktop

---

### Option 4: ML Model Training & Benchmarking (Standalone `ml_training/`)

1. Run the 1-Click Master Training Pipeline:
   python ml_training/train.py

2. Run Evaluation & Test Scripts:
   • Edge-Case & Confusion Matrix Evaluation:
     python ml_training/scripts/evaluate_classifier.py
   • Holt-Winters & ARIMA Forecaster Evaluation:
     python ml_training/scripts/evaluate_forecaster.py
   • Generate 6-Month Bank Statement PDFs (HDFC, SBI, ICICI):
     python ml_training/scripts/generate_sample_statements.py

---

## Running Automated Tests

1. Backend Pytest Suite:
   pytest backend/tests/test_backend.py -v
   (or inside Docker: docker compose exec backend pytest backend/tests/test_backend.py -v)

2. Flutter Test Suite:
   cd mobile/flutter_app
   flutter analyze
   flutter test

---

## Key Features & User Experience

1. Multi-Bank Ingestion: Upload multi-page Canara e-passbooks, HDFC, SBI, ICICI statements.
2. Uncertain Categorization: Low confidence (<60%) items default to "Uncategorized",
   and checkmarks in review screens default to "Uncategorized".
3. Active Learning: User category corrections are remembered and applied to future transactions.
4. Spending Analytics: Interactive category donut chart, monthly trends, top merchants,
   and detected recurring subscriptions.
5. Expense Forecasting: Time-series projections with 90% confidence bands.
6. Zero Residue Deletion: Deleting statements purges associated transactions, forecasts,
   and uploaded files completely.
