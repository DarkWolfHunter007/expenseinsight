## 🏃 Running the Application

### 🐳 Option 1: Run with Docker (Recommended)

1. Start the backend container with persistent storage and pre-trained SVM model:
   ```bash
   docker compose up --build
   ```

   • Backend REST API: http://localhost:8000
   • Interactive Swagger Documentation: http://localhost:8000/docs
   • Health Check Endpoint: http://localhost:8000/health

2. Container Details:
   • Lightweight Python 3.11 slim runtime (~150MB).
   • SQLite database and statement uploads persist in `./data`.
   • Trained model artifacts are mounted from `./backend/ml/models` (hot-swappable without rebuilding image).
   • The `ml_training/` folder is excluded from the Docker build context via `.dockerignore`.

---

### 💻 Option 2: Run Locally with Python (Virtual Environment)

1. Activate the virtual environment from the project root:
   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

2. Start the FastAPI development server:
   ```powershell
   uvicorn backend.app.main:app --reload --host 0.0.0.0 --port 8000
   ```

---

### 🧠 Option 3: ML Model Training & Benchmarking (Standalone `ml_training/`)

The `ml_training/` directory is 100% self-contained and can be run locally, in Google Colab, or on GPU clusters:

1. Run the 1-Click Training Pipeline (10,000 synthetic multi-bank transactions + SVM):
   ```powershell
   .\.venv\Scripts\python.exe ml_training/train.py
   ```

2. (Optional) Train with a Custom Dataset (CSV or JSON):
   ```powershell
   .\.venv\Scripts\python.exe ml_training/train.py --dataset path/to/real_transactions.csv
   ```

3. Run Individual Evaluation Scripts:
   • Edge-Case Test Suite (17 multi-bank tests):
     ```powershell
     .\.venv\Scripts\python.exe ml_training/scripts/evaluate_classifier.py
     ```
   • ARIMA Time-Series Forecaster Evaluation & Backtesting:
     ```powershell
     .\.venv\Scripts\python.exe ml_training/scripts/evaluate_forecaster.py
     ```
   • Generate Realistic PDF Bank Statements (HDFC, SBI, ICICI):
     ```powershell
     .\.venv\Scripts\python.exe ml_training/scripts/generate_sample_statements.py
     ```

## 📊 Stage-by-Stage Breakdown

| Stage | Module | Key Technology | Functionality |
| :--- | :--- | :--- | :--- |
| **1. PDF Upload** | `main.py` | FastAPI / Multipart | Ingests PDF bytes, performs security validation, and creates database record. |
| **2. Extraction** | `pdf_extractor.py` | PyMuPDF (`fitz`), pdfplumber | High-speed text extraction and layout-aware table boundary detection. |
| **3. Parsing** | `transaction_parser.py` | Regex & Date Normalizer | Parses raw lines/tables into structured transactions (date, description, amount, DR/CR, balance). |
| **4. Normalization** | `merchant_normalizer.py`| RapidFuzz (Token Ratio) | Strips bank noise (UPI/IMPS/POS) and maps merchant variations to canonical names. |
| **5. ML Categorization**| `classifier.py` | Scikit-Learn SVM, Sentence Embeddings | Calibrated LinearSVC classifier predicting 16 categories with calibrated confidence scores. |
| **6. Spending Analytics**| `analytics_service.py` | Pandas & SQLAlchemy | Calculates monthly spend, category breakdown, MoM growth rate, and recurring subscriptions. |
| **7. Forecasting** | `forecaster.py` | Statsmodels ARIMA | ARIMA time-series model producing next-month spending projection and 90% confidence bands. |
